# Beyond Illusion - Ethical Deepfake Detection System
A conceptual AI-based deepfake detection system developed as a university project

## Project Overview
The project explored how an AI system could be designed to identify deepfake media. The team proposed an approach for detecting manipulated content and presented the system design and detection process.
